## Description of the Application

CharlyTTS is a Windows desktop application for livestream creators. It runs locally on the user's own computer, connects to supported streaming platforms (YouTube, Twitch, Kick, TikTok) using credentials the user provides or authorizes, reads live chat messages, and provides text-to-speech, moderation, overlay, song request, and interactive features.
